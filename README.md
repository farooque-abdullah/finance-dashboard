# 💰 Finlytics — Finance Dashboard

A sleek, production-grade **personal finance analytics dashboard** built with React and Recharts. Features real-time chart visualisations, dark/light mode, and a clean responsive layout.

![Finance Dashboard Preview](./preview.png)

## ✨ Features

- 📊 **Area charts** — visualise income vs expenses over time
- 🍩 **Donut chart** — spending category breakdown  
- 💳 **Transaction list** — recent activity with categories and amounts
- 🌙 **Dark / Light mode** toggle
- 📱 **Responsive** — works on mobile and desktop
- 🗂️ **Multi-page navigation** — Overview, Transactions, Analytics

## 🛠️ Tech Stack

- **React 18** — component architecture
- **Recharts** — charting library
- **Vite** — fast dev server & build tool
- **CSS Variables** — for theme switching

## 🚀 Getting Started

```bash
git clone https://github.com/yourusername/finance-dashboard.git
cd finance-dashboard
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
